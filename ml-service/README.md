# CivicFix ML Service

Predicts a complaint category from citizen text (English and Roman Urdu)
using TF-IDF + Logistic Regression (scikit-learn), served by FastAPI.
It can also analyse a complaint photo with a real pretrained vision
model (MobileNetV2, ONNX) — see `POST /detect-image` below.

**Architecture rule:** React must never call this service directly.
The C++ backend will call it later. This service only exposes a clean
HTTP API for the backend to use.

## Files

```
ml-service/
├── datasets/complaints.csv   # 360 labelled examples (see below)
├── train.py                  # trains + evaluates, saves models/
├── app.py                    # FastAPI: GET /health, POST /predict, POST /detect-image
├── models/
│   ├── model.joblib          # full Pipeline (TF-IDF + classifier)
│   ├── vectorizer.joblib     # TF-IDF FeatureUnion alone
│   ├── classifier.joblib     # Logistic Regression alone
│   ├── metadata.json         # labels, version, metrics
│   ├── mobilenetv2-7.onnx    # pretrained MobileNetV2 (ImageNet, ~14 MB)
│   └── imagenet_class_index.json  # 1000 ImageNet class labels
└── requirements.txt          # incl. onnxruntime, pillow, python-multipart
```

## Dataset (demo, not production data)

`datasets/complaints.csv` has columns `text,category,language`.

| Category | Examples |
|---|---|
| Garbage Collection | 60 |
| Road Damage | 60 |
| Water Supply | 60 |
| Drainage | 60 |
| Streetlight | 60 |
| Other | 60 |
| **Total** | **360** (180 English, 180 Roman Urdu, all texts unique) |

Examples: "Garbage has not been collected from our street for five days",
"kachra nahi uthaya", "pani nahi aa raha".

This is a **template-generated demo dataset** built for this project:
real citizen complaints are messier, with more spelling variation,
mixed English/Urdu in one sentence, and categories that overlap
(e.g. a blocked drain causing a road problem). Treat the scores below
as a demo baseline, not production accuracy.

## Model

- **Features:** TF-IDF `FeatureUnion`
  - Word n-grams (1–2): whole words and short phrases
  - Character n-grams (3–5, `char_wb`): sub-word patterns, included
    because Roman Urdu spelling varies ("kachra" / "kachray")
- **Classifier:** Logistic Regression (`max_iter=1000`, `C=1.0`,
  `class_weight="balanced"`)
- **Split:** 80/20 stratified train/test, seed 42 (288 train / 72 test)

## Measured results (4 Nov 2026, this dataset)

Held-out test set (72 examples):

- Accuracy: **0.9722**
- Precision (macro): **0.9733**
- Recall (macro): **0.9722**
- F1 (macro): **0.9722**

Per-category F1: Garbage Collection 1.00, Road Damage 0.96,
Water Supply 1.00, Drainage 1.00, Streetlight 0.96, Other 0.92.
Confusion matrix (rows = true, cols = predicted, in label order
Garbage Collection, Road Damage, Water Supply, Drainage, Streetlight,
Other):

```
[[12  0  0  0  0  0]
 [ 0 12  0  0  0  0]
 [ 0  0 12  0  0  0]
 [ 0  0  0 12  0  0]
 [ 0  0  0  0 11  1]
 [ 0  1  0  0  0 11]]
```

**Why this score is optimistic:** test examples share templates and
vocabulary with the training examples, so the model has effectively
seen the same phrasing before. Real, unseen citizen text will score
lower. Before going live, collect real labelled complaints, add them
to the dataset, and re-evaluate on complaints the model has never seen.

## Install, train, run

```bash
cd ml-service

# 1. Create a virtual environment (recommended)
python -m venv .venv
# Windows:
#   .venv\Scripts\activate
# Linux / macOS:
#   source .venv/bin/activate

# 2. Install dependencies
pip install -r requirements.txt

# 3. Train (re-creates models/)
python train.py

# 4. Run the API on port 8000
uvicorn app:app --host 127.0.0.1 --port 8000
```

## Image detection — POST /detect-image (added 5 Nov 2026)

A real pretrained vision model, not a heuristic: MobileNetV2 trained
on ImageNet, run with ONNX Runtime. The model file
`models/mobilenetv2-7.onnx` (~14 MB, from the
[ONNX Model Zoo](https://github.com/onnx/models)) is downloaded once
and committed to the repo (unlike the `.joblib` files, which are
generated by `train.py` and git-ignored). If the file is ever missing,
the endpoint returns `503` — it never fakes a prediction.

```bash
curl -X POST http://127.0.0.1:8000/detect-image -F "file=@photo.jpg"
```

Response:

```json
{
  "predicted_category": "Garbage Collection",
  "confidence": 0.5864,
  "image_labels": [
    {"label": "garbage truck", "confidence": 0.5864},
    {"label": "tow truck", "confidence": 0.0854},
    {"label": "police van", "confidence": 0.0574}
  ],
  "model": "mobilenetv2-imagenet",
  "needs_human_review": false
}
```

- The photo is resized to 224×224, normalised with the ImageNet
  mean/std, run through MobileNetV2, and the logits are softmaxed;
  `image_labels` are the top-3 ImageNet labels with confidences.
- `predicted_category` is a best-effort keyword mapping from those
  top-3 labels to a CivicFix category (see `CATEGORY_KEYWORDS` in
  `app.py`): the first top-3 label whose keywords match wins, and
  `confidence` is that label's confidence. If nothing in the top-3
  maps, the category is `Other` with the top-1 confidence.
- `needs_human_review` is `true` when confidence is below 0.5 or
  the category is `Other`.
- The file field may also be named `image`. A non-image upload or a
  missing file returns `400`; an empty file returns `400`; files
  over 10 MB return `400`.
- `GET /health` also reports `image_model_loaded` and
  `image_model: "mobilenetv2-imagenet"`.

Verified responses (5 Nov 2026, service on port 8001):

```json
// Real photo of a garbage truck (Wikimedia Commons)
{"predicted_category":"Garbage Collection","confidence":0.5864,
 "image_labels":[{"label":"garbage truck","confidence":0.5864},
                 {"label":"tow truck","confidence":0.0854},
                 {"label":"police van","confidence":0.0574}],

// Random real photo (picsum, a boat scene)
{"predicted_category":"Other","confidence":0.3493,
 "image_labels":[{"label":"gondola","confidence":0.3493},
                 {"label":"fireboat","confidence":0.099},
                 {"label":"wreck","confidence":0.0938}],

// Non-image upload -> 400 {"detail":"Uploaded file is not a valid image."}
// No file at all  -> 400 {"detail":"No file uploaded: send a multipart form with a \"file\" field."}
// /predict still works: "Garbage has not been collected..." -> Garbage Collection 0.7954
```

## API contract

### GET /health

```json
{"status":"ok","service":"CivicFix ML Service","model_loaded":true,"model_version":"civicfix-ml-v1","image_model_loaded":true,"image_model":"mobilenetv2-imagenet"}
```

If the model has not been trained yet, `model_loaded` is `false`
and `/predict` returns `503` ("Model not trained yet. Run: python train.py").

### POST /predict

Request: `{"text": "..."}` (English or Roman Urdu)

Response:

```json
{
  "predicted_category": "Garbage Collection",
  "confidence": 0.7954,
  "model_version": "civicfix-ml-v1",
  "needs_human_review": false
}
```

- `confidence` is the classifier's probability for the top class.
- `needs_human_review` is `true` when confidence is **below 0.5**.
  That means "send this to an admin to check", not "reject it" —
  the prediction is still returned.
- An empty `text` is rejected with `422` validation (whitespace-only
  text with `400`).

## Honest limits

- Demo dataset only (360 template-generated examples). Not production
  accuracy, not a substitute for real labelled data.
- No Urdu script (اردو) support yet — Roman Urdu only, plus English.
  Urdu-script text will likely be low-confidence and flagged for review.
- Single-label only: a complaint about two problems gets one category.
- No priority prediction here — priority stays rule-based in the
  C++ backend (score 1–5), per the project plan.
- No authentication on this service yet. In local testing it listens
  on `127.0.0.1` only; do not expose it publicly without auth and
  rate limiting when going live.
- Image detection is a general ImageNet classifier, not a model
  trained on civic photos. It recognises what ImageNet labels
  describe (a garbage truck, a bus, a fountain) but it has no
  "pothole", "blocked drain" or "broken streetlight" class, so the
  CivicFix category is only a keyword routing hint. A lamp-post
  photo in testing was read as "pedestal" (0.687) and only mapped
  via its third label ("street sign", 0.0343) — correctly flagged
  `needs_human_review: true`, but it shows the mapping can be
  driven by a low-confidence third label. Treat every image result
  as a hint for an admin to check, never as ground truth. A model
  actually trained on labelled civic photos would be needed before
  relying on it.
- Model files (`models/*.joblib`) are generated locally by
  `train.py` and are excluded from Git by the project `.gitignore`.
  A fresh clone must run `python train.py` before starting the API.
